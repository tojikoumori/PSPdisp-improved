_PSPbeam is an independently maintained continuation and modification of PSPdisp, originally developed by Jochen Schleu. It builds upon the original project while introducing improvements, fixes and new functionality. Original software: https://www.jjs.at/software/pspdisp.html_

## Features 

- **Screenshot and video capture (with audio)** functionality, you can access it pressing the home button. it will capture the screen that is under the menu!! example screenshot i took: <img width="480" height="272" alt="pspdisp_0004" src="https://github.com/user-attachments/assets/f50b5fd4-c43f-4b00-adf5-fb0cbb56c986" />

- **PSP Color controls** (Saturation, contrast, brightness, red gain, green gain, blue gain) - you can now adjust the colors as you like

- **Mouse coordinate accuracy fix** (allows the PSP to accurately reflect the PC's mouse position)

- **No screen tearing**

- **4410 Hz Audio fix**: audio now plays better at the highest rate - still needs polishing

- **PSP button responsiveness improved** - publishing soon






## Recommended settings

[USB mode in windows 11 tutorial](https://www.reddit.com/r/PSP/comments/1fsldjm/pspdisp_usb_mode_windows_11_solution/)

**PSP:** 2/9 - Picture: Saturation 100% / Contrast: 115% / Brightness: -10% 

Change PC settings: Quality > No compression 

**PC:** Viewport size > 960x544
